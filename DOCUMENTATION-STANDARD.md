# Documentation standard

All **GiovanniLatorre** repositories use English READMEs with this structure:

1. Title + one-line tagline
2. Metadata table (Stack | Visibility | Type)
3. Overview
4. Features
5. Prerequisites
6. Quick start
7. Configuration
8. Project layout (when useful)
9. Security & data handling
10. Related projects (optional)

Never commit secrets, live `accounts.yaml`, or raw evidence exports.
